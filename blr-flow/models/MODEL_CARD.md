# BLR Flow model card

## Intended use

A Bengaluru-inspired regression simulator with hourly charts and scenario comparisons. Educational portfolio/research demonstration. Not an automated high-stakes decision tool.

## Data

17,280 synthetic hourly observations over 120 days at six named junctions. Illustrative offsets and rush-hour curves are assumptions, not observations.

## Model

24-tree random forest regressor (max depth 8), with cyclical hour encodings, junction index and scenario flags.

## Evaluation

Time-ordered split: 12,960 Jan-Mar train rows / 4,320 April test rows. MAE 3.47 index points; R² 0.943 on synthetic data only.

Metrics are generated by `training/train.py` and stored alongside weights. Split and preprocessing are recorded in the artifact. Numerical Python-to-JavaScript parity is tested, but parity is not a validation of the model's real-world suitability.

## Limitations

Use licensed measured traffic data, add rolling-origin validation and exogenous forecasts, and validate calibrated prediction intervals. Not usable as live route guidance.

## Explanations

Job and health bars are signed additive **log-odds contributions**, not causal effects, SHAP values or medical advice. Resume skill coverage is dictionary presence, not expertise. Traffic index bands are arbitrary project conventions.

## Deployment

JSON weights consumed locally in the browser. No retraining at deployment. No input persistence.
